# IW4-Custom-Maps
A repository for custom map release for PS3, Modern Warefare 2 (2009) (IW4)

## Platform
These maps are for the Playstation 3 Platform Only.

### How to use
Utilize the patch_mp.ff in this repo, in addition use the patched binaries located here: https://github.com/jacob-schroeder/IW4-Binaries
Place both of them in your game update directory:
```
/dev_hdd0/game/{region}/usdir
```
Then create a "mods" folder in your game update directory:
```
/dev_hdd0/game/{region}/usdir/mods
```
Place any custom maps in that directory and they will automatically be loaded under the "Custom Maps" menu in multiplayer.
